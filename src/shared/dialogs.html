History

Your last searches, kept in this browser only. Only the settings are kept, not the results: running a search again gives a new random selection.

    Settings file

    Save all your settings to a file, to use them again later or to give them to someone else. Loading the file sets everything as it was. Your Google key is never in it.

    Start a new search?

    Since you stopped the search, you changed settings that decide which locations are found:

      The locations found so far were found with the old settings. Some of them may not fit the new ones, and the page cannot tell which, so the search cannot go on with them. A new search starts from scratch and replaces them.

      To keep them, cancel and download the map file first, or change those settings back and continue the stopped search. Only the number of locations, how far to look around each spot, the lookups at the same time and giving up can change while keeping what was found.
